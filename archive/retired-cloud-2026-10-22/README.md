# Исторические проверки отключённых функций

22 октября 2026 года по запросу владельца приложение переведено на одну текущую локальную кампанию. Firebase, авторизация, каналы синхронизации, создание/подключение комнаты и замена кампании через JSON удалены из активного runtime. Эти файлы сохранены как свидетельства прежнего поведения; они не входят в `tests/*.test.*`, команды приёмки или Pages allowlist и больше не запускаются против текущего приложения.

- `tests/campaign-import.test.mjs`: атомарность прежней замены кампании, отказ ввода, журнал и каталоги.
- `tests/campaign-sync-guards.test.mjs`: входящие/исходящие сообщения, конфликты и dirty-generation.
- `qa/import-export.e2e.cjs`: прежний браузерный цикл скачивания и загрузки JSON.
- `retired-test-cases.txt`: выделенные облачные проверки из общих наборов, прежний смешанный load/import source-contract и импортная проверка повреждённой истории MP.

Регрессии локального сохранения, подтверждения записи, очереди, CAS, защиты от закрытия и отката игровых действий продолжают выполняться. Проверки происхождения призывов, эффектов, доступа к магии и дубликатов заклинаний переведены на локальную запись и загрузку. Новый набор `tests/local-campaign-persistence.test.mjs` и `qa/local-persistence.e2e.cjs` проверяет продолжение той же партии без начального заполнения или сброса боя. Повреждённая история MP проверяется при загрузке локального снимка.

История Git не переписана. Реальные пользовательские локальные ключи, резервные данные и удалённая база не очищались. Исторические облачные файлы распознаёт только непубликуемый read-only `scripts/save-inspector.mjs`; этот инструмент не имеет сетевого подключения и не загружает данные в приложение.
