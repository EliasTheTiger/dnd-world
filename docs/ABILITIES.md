# Способности и черты: сверка и исполнение

Ревизия `abilities-ru-2026-09-07.1` проверяет все **693** записи рабочего каталога. Исправлены **388 названий** и **224 описания** (включая точечную терминологическую редактуру). Старые названия и идентификаторы сохраняются: поиск понимает старое название, английское имя источника и варианты е/ё.

## Что подтверждено

Источник названий — [глоссарий Hobby World](https://hobbyworld.ru/download/rules/Glossary5E_2.xlsx), опубликованный на [странице дополнительных материалов издателя](https://hobbyworld.ru/news/dopolnitelnie-fajli-k-nri). Для каждого совпадения сохранены SHA-256 исходного файла, лист и ячейка. Тип записи учитывается: `Grappler` как черта — **«Рукопашный борец»**, а не одноимённая способность чудовища; `Lucky` полурослика — **«Удача»**, а не черта **«Счастливчик»**. `Tough` в мастере создания показывается как **«Живучий»**; старое значение «Крепкий» остаётся внутренним ключом сохранения.

- 232 названия записей D&D 2014 подтверждены глоссарием, включая общие правила вроде мировоззрения и скорости.
- 162 названия авторских записей и редакции 2024 используют найденную терминологию, без заявления об официальном переводе этих правил.
- 299 названий — перевод или формулировка проекта; совпадение с Hobby World не подтверждено.
- 25 полных описаний (19 правил с повторяющимися расовыми карточками) вычитаны по [SRD 5.1](https://media.dndbeyond.com/compendium-images/srd/5.1/SRD_CC_v5.1.pdf). Это пересказы проекта, а не текст русского издания.
- Остальные 668 описаний требуют полной сверки. Наличие русского текста и исправление отдельных терминов не доказывают точность всего правила.

**Полное соответствие всех описаний русскому изданию Hobby World не подтверждено:** открытый глоссарий содержит названия, но не полные правила. Официальный доступный файл исправлений к «Книге игрока» содержит таблицу чародея и инструменты барда; он не заменяет главы о способностях и чертах. В каждой карточке статус названия и описания показан отдельно.

Состав: 318 записей D&D 2014, 309 справочных записей D&D 2024, 45 авторских записей и 21 запись Black Flag. Справочные карточки 2024 доступны в отдельном фильтре и не выдаются герою кампании 2014 обычной кнопкой. Исходный импорт `open5e-cc-v1` сохранён без изменения контрольных сумм. Редакционная адаптация выполняется при загрузке, импорте сохранения и создании каталога; ручные изменения через редактор помечаются и сохраняются при последующих обновлениях.

## Исполнение и исправления

- Каноническое «Второе дыхание» 2014: бонусное действие, лечение 1d10 + уровень воина из введённого игроком результата, одно использование до короткого или долгого отдыха. Ввод и отмена лечения предшествуют транзакции ресурсов.
- Канонический «Порыв к действию» 2014: одно дополнительное действие, без дополнительного бонусного действия; с 17-го уровня воина два использования между отдыхами, максимум одно за ход. Счётчик отображает максимум конкретного героя.
- Применение проверяет владение способностью, существование цели, состояние героя, известность требуемых исходов, корректность чисел и доступность ресурсов до коммита.
- Неизвестный результат атаки, спасброска или состязания не разрешает эффект. Успешный спасбросок или промах не обходится противоречащим ему `effectAllowed: true`.
- У «Шокирующей атаки» сохраняется явное авторское правило сравнения с КД: испытание нужно при равенстве; неизвестный результат не расходует ресурс, подтверждённое превышение разрешает эффект без лишнего испытания.
- Длящийся эффект способности на герое теперь получает срок, `casterId` и `castId`, как эффект на противнике. Последствия одного применения получают общий идентификатор.
- Повторная выдача не обнуляет расход. Для «Рукопашного борца» при выдаче проверяется Сила 13. Описание 2014 исправлено: обездвиживание требует нового состязания захвата, а не испытания, и при успехе обездвиженными становятся оба участника (ключ состояния сайта — «Опутанный»). Полное автоматическое исполнение этой черты пока отсутствует.
- В описаниях используются общие термины Hobby World: «испытание», «фокус», «долгий отдых», «лучистый урон». Парсер распознаёт термин «испытание» при редактировании способности и сохраняет проверку исхода перед наложением эффекта.
- Каталог выводит 40 карточек на страницу, предоставляет фильтры источника и применения; поиск кэширует нормализованный текст с обновлением после редактирования и сохраняет фокус ввода. По умолчанию показаны 2014 и авторские правила. После сохранения редактор показывает изменённую карточку. Особенности предыстории больше не пропадают из книги способностей героя.

Исполняемые правила не перекомпилируются из исправленного описания. Неавтоматизированные правила остаются справочными. Все остальные существующие обработчики сохраняются; эта ревизия не заявляет автоматизацию всех 693 записей.

## Воспроизведение

`scripts/extract-hobbyworld-ability-terms.py` читает скачанный XLSX без изменения исходника и создаёт `scripts/hobbyworld-ability-terms.js`. Последний содержит только короткие терминологические записи и атрибуцию, не полный текст книг. `scripts/ability-rules.js` содержит редакционные исправления и политику поиска/выдачи.

```text
python scripts/extract-hobbyworld-ability-terms.py path/to/Glossary5E_2.xlsx
node scripts/audit-abilities.mjs
node scripts/audit-abilities.mjs --check
node --test tests/abilities.test.mjs
node --test tests/*.test.*
git diff --check
```

Полный перечень карточек, статусов и ссылок на ячейки источника: [ability-audit.json](ability-audit.json). Лицензия и атрибуция английского SRD сохранены в [SRD51-NOTICE.md](../data/dnd5e/SRD51-NOTICE.md).
