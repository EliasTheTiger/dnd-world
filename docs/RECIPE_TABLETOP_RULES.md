# Настольные правила сорока предметов рецептов

Для каждой из 40 ранее проблемных записей выбран один предмет игры. Базовый яд и зелье героизма используют существующие определения; остальные 38 имеют собственные структурированные свойства. Это адаптация для данной кампании по поручению владельца, а не утверждение, что уникальные изделия описаны в официальных книгах D&D.

Основа обычных аналогов: D&D 5e (2014), [снаряжение](https://www.dndbeyond.com/sources/dnd/basic-rules-2014/equipment), [магические предметы](https://www.dndbeyond.com/sources/dnd/basic-rules-2014/magic-items), [типы ядов](https://www.dndbeyond.com/sources/dnd/basic-rules-2014/running-the-game), [заклинания](https://www.dndbeyond.com/sources/dnd/basic-rules-2014/spells). Уникальные свойства переведены в действия, раунды, спасброски и ресурсы этой игры.

Все кости вводят игроки. Конкретные цели, фактический контакт с кожей, положение в области и ответы существ подтверждает мастер; сайт применяет проверяемые последствия и сохраняет расход.
