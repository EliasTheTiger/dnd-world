# Каталоги заклинаний, способностей и черт D&D 5e

Актуальный проверяемый минимум проекта:

- заклинания: 958 записей в рабочей базе (121 локальная + 837 импортированных), 515 уникальных русских названий только в импортированной части;
- способности и черты: 693 записи в рабочей базе (77 локальных + 616 импортированных);
- импортированные способности: 454 классовых особенности, 144 расовых особенности и 18 черт;
- исключения: одна запись SRD 5.2 (`Greater Invisibility`) удалена из рабочего набора, потому что источник вернул её без описания.

Импорт использует только документы, которые Open5e помечает лицензией CC-BY-4.0. Все пользовательские поля — названия, описания, классы, время, дистанция, компоненты, длительность и источники — закреплены в русской локализации. Исходные английские названия, ключи и ссылки сохранены только как служебные метаданные для стабильных идентификаторов и атрибуции. Точные источники, локализация и контрольные суммы находятся в [`data/dnd5e/open5e-cc-v1/manifest.json`](../data/dnd5e/open5e-cc-v1/manifest.json), [`localization.ru.json`](../data/dnd5e/open5e-cc-v1/localization.ru.json) и [`NOTICE.md`](../data/dnd5e/open5e-cc-v1/NOTICE.md).

Каждая запись сразу получает контракт движка. Проверенное заклинание SRD 5.1 «Причинение ран» имеет структурированный обработчик атаки, урона и усиления ячейкой. Остальные импортированные правила доступны для поиска и выдачи героям, но работают fail-closed: до появления отдельного проверенного обработчика они не могут списать действие, ячейку, заряд или изменить мир. Записи SRD 5.2 дополнительно помечены неактивным ruleset `dnd5e-2024-reference` и не наследуют автоматически семантику активного движка 2014 года.

Проверки:

```text
node scripts/build-dnd5e-open-catalog.mjs --check
node --test tests/dnd5e-open-catalog.test.mjs
```
