# Third-party D&D 5e catalog notices

The generated catalog in this directory contains only source documents that Open5e marks as Creative Commons Attribution 4.0. The project preserves each record's document key, publisher, game-system key, permalink, and Open5e API resource URL.

The Russian display text is a project-maintained translation and terminology adaptation of the English source records. Stable source keys, original names, rules metadata, and attribution links are preserved alongside the translation.
